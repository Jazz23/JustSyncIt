# JustSyncIt

JustSyncIt is a single zero dependency python script capable of synchronizing game save files across multiple devices, using the power of [rclone](https://rclone.org/) and **any** cloud storage provider of your choosing. Yes, this is NOT peer-to-peer; the host **can be offline**. Nothing is installed when running the script, as rclone is a simple CLI tool. All files generated by the script are kept in the local folder.

## Getting Started

[Download](https://jazz23.github.io/JustSyncIt/justsyncit.py) and run the script 👍.
